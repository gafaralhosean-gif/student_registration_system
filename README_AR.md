# نظام تسجيل الطلاب (Student Registration System)

## 1. نبذة عن المشروع
نظام ويب لإدارة بيانات الطلاب، يتيح للمستخدم إنشاء حساب وتسجيل الدخول، ثم إضافة سجلات الطلاب وعرضها والبحث فيها وتعديلها وحذفها. يدعم النظام رفع صورة شخصية اختيارية لكل طالب، مع واجهة عربية متجاوبة.

## 2. التقنيات المستخدمة
- HTML5 لبناء صفحات الموقع.
- CSS3 لتنسيق الواجهة.
- JavaScript للتحقق من النماذج والتفاعلات.
- Bootstrap 5 لتصميم واجهة متجاوبة.
- PHP لمعالجة الطلبات وإدارة الجلسات.
- MySQL لتخزين بيانات المستخدمين والطلاب.
- PDO للاتصال بقاعدة البيانات وتنفيذ الاستعلامات.

## 3. متطلبات التشغيل
- XAMPP أو خادم محلي يدعم PHP وMySQL.
- متصفح إنترنت حديث.
- تفعيل خدمتي Apache وMySQL من لوحة تحكم XAMPP.
- اتصال بالإنترنت عند تحميل Bootstrap من شبكة CDN.

## 4. طريقة التثبيت والتشغيل على XAMPP
1. فك ضغط ملف المشروع.
2. انسخ مجلد `student_registration_system_redesigned` إلى:
   `C:\xampp\htdocs\`
3. افتح لوحة تحكم XAMPP وشغّل Apache وMySQL.
4. افتح phpMyAdmin من الرابط:
   `http://localhost/phpmyadmin`
5. اختر **Import / استيراد**، ثم حدد ملف `database.sql` الموجود داخل مجلد المشروع، ونفّذ الاستيراد. ينشئ الملف قاعدة البيانات `student_registration_system` والجداول المطلوبة تلقائياً.
6. افتح الموقع من المتصفح:
   `http://localhost/student_registration_system_redesigned/`

## 5. إعداد الاتصال بقاعدة البيانات
إعدادات الاتصال موجودة في الملف:
`config/config.php`

الإعدادات الافتراضية للمشروع على XAMPP هي:
- Host: `127.0.0.1`
- Database: `student_registration_system`
- Username: `root`
- Password: فارغة

إذا كانت إعدادات MySQL على جهازك مختلفة، عدّل القيم في `config/config.php` بما يناسب بيئتك.

## 6. طريقة استخدام الموقع
1. افتح الصفحة الرئيسية.
2. اختر **إنشاء حساب**، وأدخل اسم المستخدم والبريد الإلكتروني وكلمة المرور وتأكيدها.
3. بعد إنشاء الحساب، انتقل إلى **تسجيل الدخول** واستخدم اسم المستخدم أو البريد الإلكتروني مع كلمة المرور.
4. من قائمة الطلاب اختر **إضافة طالب**، ثم أدخل الاسم والبريد الإلكتروني ورقم الهاتف والعنوان. يمكنك أيضاً إضافة صورة شخصية اختيارية.
5. من صفحة **قائمة الطلاب** يمكنك عرض السجلات والبحث بالاسم أو البريد الإلكتروني أو رقم الهاتف.
6. استخدم زر **تعديل** لتحديث بيانات الطالب.
7. استخدم زر **حذف**، ثم أكد العملية لحذف السجل.
8. اختر **تسجيل الخروج** لإنهاء الجلسة.

## 7. الوظائف المتوفرة
- إنشاء حساب مستخدم وتسجيل الدخول والخروج.
- تخزين كلمات المرور بصورة مجزأة باستخدام `password_hash()` والتحقق منها باستخدام `password_verify()`.
- حماية صفحات إدارة الطلاب بتسجيل الدخول والجلسات.
- إضافة بيانات الطلاب وعرضها وتعديلها وحذفها (CRUD).
- رفع صورة شخصية اختيارية بصيغ JPG وPNG وGIF وWEBP، وبحد أقصى 2MB.
- البحث عن الطلاب بالاسم أو البريد الإلكتروني أو رقم الهاتف.
- تقسيم النتائج إلى صفحات، بواقع 10 سجلات في الصفحة.
- التحقق من مدخلات نموذج الطالب باستخدام AJAX دون إعادة تحميل الصفحة أثناء التحقق.
- واجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار وتصميماً متجاوباً.

## 8. بنية المجلدات الرئيسية
- `index.php` : الصفحة الرئيسية.
- `register.php` : إنشاء حساب جديد.
- `login.php` : تسجيل الدخول.
- `logout.php` : تسجيل الخروج.
- `students/` : صفحات إضافة الطلاب وعرضهم وتعديلهم وحذفهم.
- `api/validate_student.php` : التحقق من بيانات نموذج الطالب عبر AJAX.
- `config/` : إعدادات المشروع والاتصال بقاعدة البيانات.
- `inc/` : الدوال المشتركة وترويسة وتذييل الصفحات.
- `assets/css/` : ملفات تنسيق الموقع.
- `assets/js/` : ملفات JavaScript.
- `uploads/` : الصور الشخصية المرفوعة.
- `database.sql` : إنشاء قاعدة البيانات والجداول.

## 9. ملاحظات مهمة
- يجب أن يكون مجلد `uploads` قابلاً للكتابة من قبل PHP حتى يتم حفظ صور الطلاب.
- لا تحذف ملف `database.sql`؛ فهو مطلوب لإنشاء قاعدة البيانات.
- لا ترفع بيانات دخول حقيقية أو كلمات مرور خاصة إلى مستودع عام.
- هذه التعليمات مخصصة للتشغيل المحلي على XAMPP. عند النشر على استضافة ويب، يجب ضبط بيانات قاعدة البيانات وفق بيانات الاستضافة واتباع تعليمات مزود الخدمة.
